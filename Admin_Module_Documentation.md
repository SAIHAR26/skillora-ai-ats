# SKILLORA
## Admin Module Documentation
 
## 1. Introduction :
The Admin Module is the central control system of the Skillora platform. It allows administrators to manage recruiters, candidates, opportunities, complaints, interviews, notifications, reports, and system settings. The admin ensures smooth operation, security, and transparency across the platform. This module helps monitor all activities and maintain the quality of the recruitment process.

## 5. Recruiter Verification :
Purpose:
The Recruiter Verification module ensures that only genuine recruiters and companies can access the Skillora platform.

### Verification Process:
1. Recruiter Registration
2. Admin Reviews Recruiter Details
3. Admin Verifies Company Information
4. Admin Approves or Rejects Recruiter

### Verification Details:
• Company Name
• Company Email
• Company Website
• Company Address
• Industry Type
• Company Size
• LinkedIn Profile

### Admin Actions:
• Approve Recruiter
• Reject Recruiter
• Request Additional Information

### Note:
Recruiters can log in only after admin approval.
