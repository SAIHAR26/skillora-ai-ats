# Skillora

AI-Powered Applicant Tracking and Candidate Ranking System

## Overview

Skillora is a MERN Stack recruitment platform that helps recruiters manage job openings, analyze resumes, rank candidates using AI, and streamline the hiring process.

## Features

- Recruiter Dashboard
- Applicant Portal
- Resume Upload
- AI Resume Analysis
- Candidate Ranking
- Application Tracking
- Email Notifications
- Analytics Dashboard
